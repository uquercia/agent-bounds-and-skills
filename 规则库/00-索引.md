# 规则库索引

本目录用于承接低频、场景化、说明型规则，避免把所有细则长期堆在全局 `AGENTS.md` 中。

## 使用方式
- 命中某个专题场景时，再读取对应文档。
- 若场景同时涉及多个专题，先读最直接影响当前决策的文档，再按需要补读其他文档。
- 若规则库文档与全局 `AGENTS.md` 冲突，以全局 `AGENTS.md` 的硬约束为准。

## 专题文档
- `01-项目存档与续接规范.md`
  - 适用：项目首次进入、每日记录、会话恢复、项目档案补齐。
- `02-provider-混用与重连修复.md`
  - 适用：provider 混用、记忆分裂、`Reconnecting...`、桌面端与 CLI 表现不一致。
- `03-AGENTS与技能同步规范.md`
  - 适用：修改全局 `AGENTS.md`、skills、规则文档，或需要同步到 `G:\codex_skills`。
- `04-git提交与推送规范.md`
  - 适用：需要提交 `G:\codex_skills`、整理提交信息、控制提交范围、处理推送失败。
- `05-Review输出规范.md`
  - 适用：用户要求像 Cursor 一样 Review，或需要 High/Medium/Low + `path:line` 定位。
- `06-删除与批量操作细则.md`
  - 适用：批量删除、目录树清理、跨工作区操作、系统路径风险判断。
- `07-本地技能清单.md`
  - 适用：需要确认已安装技能、技能路径、优先使用哪个技能。
