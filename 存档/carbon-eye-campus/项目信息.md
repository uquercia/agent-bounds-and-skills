# 项目信息：carbon-eye-campus

## 项目目标
- 面向中兴大学的校园低碳行为与水电预测驾驶舱。
- 统一展示学生低碳行为、楼栋水电数据、预测结果、识别样例和训练结果。
- 当前既有本地开发链路，也有云端 Docker / 宿主机 Nginx 部署链路。

## 仓库路径
- `G:\codex\carbon-eye-campus`

## 技术栈
- 前端：Vue 3、Vite、TypeScript、Element Plus、Apache ECharts、lucide-vue-next、Axios
- 后端：FastAPI、Uvicorn、SQLAlchemy、PyMySQL
- 数据库：MySQL 8.4
- 算法/图像：OpenCV、Pillow、PyTorch、Ultralytics YOLO
- 部署：Docker Compose、Nginx

## 主要功能
- 首页驾驶舱：趋势指数、楼栋关系图、楼栋水电表、趋势图、行为影响图、训练图片展示。
- 图片上传识别：上传校园图片，创建识别任务，轮询任务状态。
- 聚合接口：`GET /api/dashboard` 一次返回首页所需数据。
- 健康检查：`GET /api/health`。
- 静态答辩页：`/api/html/` 和 `/defense/`。

## 启动与构建
### 本地前端
- 目录：`G:\codex\carbon-eye-campus\apps\web`
- 安装：`npm.cmd install`
- 开发：`npm.cmd run dev -- --host 127.0.0.1 --port 5173`
- 构建：`VITE_API_BASE_URL=/api npm.cmd run build`

### 本地后端
- 根目录：`G:\codex\carbon-eye-campus`
- 初始化数据库：`.\.venv\Scripts\python.exe apps\api\scripts\init_db.py`
- 启动接口：`.\.venv\Scripts\python.exe -m uvicorn apps.api.app.main:app --host 127.0.0.1 --port 8000`

### 云端现状
- 当前公网 80 端口实际由宿主机 Nginx 提供静态页。
- API 通过宿主机回环 `127.0.0.1:8000` 转发到 `carbon-eye-api` 容器。
- 数据库使用 Docker 内 `carbon-eye-db`，`DATABASE_URL` 指向 `db:3306`。
- `carbon-eye-web` 容器当前不是线上主链路，已清理停止态容器。

## 关键环境变量
- `DATABASE_URL`：后端数据库连接串。
- `MYSQL_ROOT_PASSWORD`：MySQL root 密码。
- `MYSQL_APP_PASSWORD`：应用数据库密码。
- `VITE_API_BASE_URL`：前端 API 基址，生产应使用 `/api`。
- `PUBLIC_UPLOAD_BASE_URL`：上传文件公网访问基址。
- `VISION_PROVIDER`、`VISION_API_KEY`、`VISION_BASE_URL`、`VISION_MODEL`：视觉识别配置。

## 常见问题与排障口径
- 页面提示“后端 API 未连接”时，先查前端 bundle 里的 `VITE_API_BASE_URL` 是否被打成本机地址。
- 公网 `/api/health` 和 `/api/dashboard` 若返回 `200`，优先排查前端静态包和浏览器缓存。
- 若 `carbon-eye-web` 容器退出，不代表数据库断开；当前公网可能是宿主机 Nginx 在直接服务静态目录。
- 数据库链路实际应检查 `carbon-eye-api` 容器内的 `DATABASE_URL` 是否指向 `db:3306`。
